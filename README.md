# AROGYA-MITRA

AI-powered healthcare system that analyzes medical documents to provide treatment cost predictions, hospital comparisons, and government scheme eligibility detection.

## Team
- Team Name: Karishma
- Team Leader: Karishma

## Features
- AI-based medical document analysis
- Treatment cost prediction across hospitals
- Hospital comparison (cost, success rate, reviews)
- Government healthcare scheme eligibility (Ayushman Bharat, etc.)
- Affordable treatment recommendations
- Alternative treatment suggestions

## Tech Stack
- Amazon Bedrock (AI analysis)
- AWS Lambda (Serverless processing)
- Amazon S3 (Document storage)
- Amazon DynamoDB (Hospital database)
- API Gateway (REST APIs)
- Python, HTML, CSS, JavaScript

## Setup
```bash
pip install -r requirements.txt
```

## Run Locally
```bash
python app.py
```
